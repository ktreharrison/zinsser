# RFC 8174: interpreting RFC 2119 keywords

RFC 8174 clarifies that the requirement words defined by RFC 2119 carry their special meanings only when written in uppercase. It does not prescribe a document outline or require a goal statement or examples.

When editing a document that uses RFC 2119 terminology:

- Preserve uppercase `MUST`, `MUST NOT`, `REQUIRED`, `SHALL`, `SHALL NOT`, `SHOULD`, `SHOULD NOT`, `RECOMMENDED`, `NOT RECOMMENDED`, `MAY`, and `OPTIONAL` when they carry normative meaning.
- Do not treat lowercase uses as normative keywords under RFC 8174.
- Consult RFC 2119 for the definitions and caveats associated with each keyword.
